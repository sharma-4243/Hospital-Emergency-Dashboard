# Hospital Emergency Room Dashboard

## Project Overview
This dashboard analyzes hospital emergency room data using Excel.

## Features
- Patient count KPI
- Average wait time
- Patient satisfaction score
- Gender analysis
- Age group analysis
- Department referral analysis
- Monthly filtering
- Year selection

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- GETPIVOTDATA
